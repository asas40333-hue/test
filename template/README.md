# 메종플러스 현장 웹앱 표준 템플릿

새 현장이 들어오면 이 폴더를 통째로 복사해 씁니다. 한빛 현장 파일(저장소 맨 위 `index.html`·`partner.html`)은 건드리지 않습니다.

## 파일 구성

| 파일 | 고치나요? | 내용 |
|---|---|---|
| `site.js` | **고칩니다** | 현장명, 착공·완공일, 작업 요일, 공휴일, 소음 시간, **공정 일정(한 번만 적으면 고객·협력업체 화면 모두 반영)** |
| `index.html` | 내용만 | 고객용: 카톡 미리보기(og), 현장일지 카드, 자재 카드, 맨 아래 `PAYMENT`(계약·정산) |
| `partner.html` | 내용만 | 협력업체용: 카톡 미리보기(og), 공사 전 사진·특이사항, 맨 아래 `ACCESS`(주소·출입·연락처·수칙) |
| `app.js` | **고치지 않음** | 진행률·공사 일차 계산, 공정표, 달력, 상세창, 사진 확대 (틀) |
| `manifest*.json` | 설명 한 줄 | 홈 화면 바로가기 이름 |
| `images/` | 사진 넣기 | `sample.svg`는 자리 표시용 그림이라 실제 사진으로 바꿉니다 |

## 새 현장 만드는 순서

1. 이 `template` 폴더를 복사해 **저장소 맨 위에** 현장 약칭 폴더로 만듭니다. (예: `eundong-1406/`)
   폴더 깊이가 같아야 회사 공통 아이콘(`../icon-192.png`)과 자재 도감(`../catalog.html`) 연결이 맞습니다.
2. `site.js`: `id`(폴더 이름과 같게), `name`, `start`, `end`, `holidays`, `noiseHours`, `SCHEDULE`을 고칩니다.
3. `index.html`·`partner.html` 맨 위의 `og:` 다섯 줄에서 대괄호 `[ ]`를 바꿉니다. 카카오톡은 스크립트를 읽지 않아서 여기는 직접 적어야 합니다.
4. `partner.html` 맨 아래 `ACCESS`에 주소·로비·연락처·수칙을 적습니다. **현관 비밀번호(`doorCode`)는 빈칸으로 두고 문자로 안내하는 것이 기본**입니다.
5. `index.html` 맨 아래 `PAYMENT`: 금액 표시는 고객님 동의를 받은 뒤 넣습니다. 동의가 없으면 `show: false`로 둡니다.
6. 사진은 긴 쪽 1200px로 줄여 `images/`에 `현장약칭_day01_01.jpg`처럼 넣고, 예시 카드의 `images/sample.svg`를 바꿉니다.
7. 화면 안에 남은 `[` 를 검색해 대괄호가 하나도 남지 않았는지 확인합니다.
8. 날짜를 바꿔 가며 확인합니다. 주소 끝에 `?today=착공 전날`, `?today=공사 중 날짜`, `?today=공휴일`, `?today=완공 다음 날`을 붙여 진행률·달력·상세창을 봅니다.
   예: `https://asas40333-hue.github.io/test/eundong-1406/?today=2027-01-04`

## 공사 일차 기준

`site.js`의 `dayBase`로 정합니다. 상단 카드, 공정표, 달력 상세창이 모두 같은 기준을 씁니다.
- `'workday'`(기본): 작업 요일만 셉니다. 주말·공휴일은 일차에 들어가지 않습니다. 현장일지 카드의 'N일차'도 이 기준으로 적습니다.
- `'calendar'`: 착공일부터 달력 날짜로 셉니다.

## 완공 후

- `ACCESS.doorCode`를 적었다면 지우고, 고객님께 도어락 번호 변경을 안내합니다. (저장소 수정 기록에는 예전 번호가 남습니다)
- 현장 폴더는 지우거나 옮기지 않습니다. 고객님 휴대폰의 바로가기 링크가 계속 살아 있어야 합니다.
