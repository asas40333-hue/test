# 인테리어 현장 공유 웹앱 · 사용 설명서

고객님께는 **공사 진행률·현장 사진·공정 일정·정산 내역**을, 협력업체에는 **현장 주소·출입 방법·공정표**를 링크 하나로 보내는 웹앱입니다.
코딩을 몰라도 됩니다. **파일 두 개(site.js, data.js)의 글자만 바꾸고, 폴더를 끌어다 놓으면** 링크가 만들어집니다.

---

## 0. 폴더 안에 들어 있는 것

| 파일 | 고치나요? | 하는 일 |
|---|---|---|
| `site.js` | ✏️ **처음 한 번** | 회사명·대표 이름·연락처·색상·자재 도감 연결 |
| `data.js` | ✏️ **현장마다** | 현장명·일정·현장 일지·자재·정산·출입 안내·공사 전 사진 |
| `images/` | 📷 사진 넣기 | 현장 사진을 넣는 곳 (지금은 샘플 그림이 들어 있습니다) |
| `index.html` | 고치지 않음 | 고객용 화면 |
| `partner.html` | 고치지 않음 | 협력업체용 화면 |
| `app.js` | 고치지 않음 | 화면을 자동으로 그려 주는 파일 |
| 아이콘·미리보기 그림 (`icon-*.png`, `og-*.png`, `manifest*.json`) | 그대로 사용 | 휴대폰 홈 화면 아이콘, 카톡 미리보기 그림 |

> 💡 **처음엔 고치지 말고 그대로 올려 보세요.** 가상의 「샘플아파트 32평형」 현장이 채워져 있어서 바로 시연할 수 있습니다.

## 1. 5분 만에 링크 만들기 (Netlify Drop · 무료)

1. 컴퓨터 인터넷 창에서 **app.netlify.com** 에 들어가 **무료 회원가입**을 합니다. (구글 계정으로 버튼 한 번)
   - 로그인 없이 올리면 임시 사이트가 되어 **1시간 안에 지워집니다.** 꼭 먼저 가입하세요.
2. 로그인한 뒤 주소창에 **app.netlify.com/drop** 을 입력합니다.
3. 이 **폴더 전체**를 마우스로 끌어다 화면의 점선 상자 안에 놓습니다.
   - 압축 파일(.zip)로 받으셨다면 **압축을 먼저 풀고**, 파일들이 들어 있는 폴더를 끌어다 놓습니다.
4. 10초쯤 지나면 `https://영어단어-123abc.netlify.app` 같은 주소가 생깁니다. 이것이 내 현장 링크입니다.
   - **고객용 링크:** 받은 주소 그대로
   - **협력업체용 링크:** 받은 주소 끝에 `/partner.html` 을 붙입니다
5. (선택) 사이트 설정 → **Change site name** 에서 주소 앞부분을 `myhome-1203` 처럼 바꿀 수 있습니다.

### 내용을 고친 뒤 다시 올리는 법
Netlify 에서 해당 사이트 → **Deploys(배포)** 메뉴 → 아래쪽 점선 상자에 **고친 폴더를 다시 끌어다 놓습니다.**
링크 주소는 바뀌지 않아서, 고객님 휴대폰의 링크가 그대로 새 내용을 보여 줍니다.

> 현장이 여러 개면 현장마다 폴더를 복사해서 **사이트를 따로 하나씩** 만드세요.

## 2. 회사 정보 바꾸기 — `site.js` (처음 한 번)

파일을 **메모장**(맥은 텍스트 편집기)으로 엽니다. 마우스 오른쪽 → 연결 프로그램 → 메모장.

```js
company: '샘플인테리어',     ← 회사명
ceoName: '홍길동',           ← 대표 이름
ceoTitle: '대표',            ← 직함
phone: '010-0000-0000',      ← 연락처
career: '현장 경험 20년',    ← 한 줄 소개
```

- **작은따옴표 `' '` 안의 글자만** 바꿉니다. 따옴표와 쉼표는 지우지 않습니다.
- **색상:** `primary` 에 회사 대표 색을 적습니다. 구글에서 "색상 선택기"를 검색하면 `#1e3a8a` 같은 코드를 볼 수 있습니다.
- **자재 도감 연결 (선택):** 회사 자재 사진 페이지나 블로그가 있다면 `catalog` 의 `show: false` 를 `true` 로 바꾸고 `url` 에 주소를 적습니다. 없으면 그대로 두세요. 배너가 숨겨집니다.

저장하면 고객용·협력업체용 화면의 회사명, 연락처, 전화 버튼, 색상이 **모두 한꺼번에** 바뀝니다.

## 3. 현장 정보 바꾸기 — `data.js` (현장마다)

파일 안에 1번부터 7번까지 칸이 나뉘어 있고, 칸마다 설명이 적혀 있습니다.

| 칸 | 바꾸는 내용 |
|---|---|
| **1. 현장 기본 정보** | 현장명, 착공일, 완공일, 작업 요일, 휴무일, 소음 허용 시간 |
| **2. 공정 일정** | 공정별 날짜와 이름 (고객·협력업체 리스트와 달력에 함께 나옴) |
| **3. 현장 일지** | 날짜·제목·설명·사진 (최신 글이 자동으로 맨 위, 'N일차'도 자동 계산) |
| **4. 자재 스펙** | 공간별 자재 카드 (확정 / 추천·협의 중) |
| **5. 계약·정산** | 계약 금액, 회차별 입금, **추가·변경 견적(+/-)** |
| **6. 출입·안내** | 주소, 공동현관, 현관 비밀번호, 주차, 현장 수칙 |
| **7. 공사 전 사진·특이사항** | 협력업체에 보여 줄 공사 전 사진과 주의할 곳 |

### ★ 실제 현장에 쓰기 전에 꼭 할 일
`data.js` 맨 위의 `demo: true` 를 **`demo: false`** 로 바꿉니다.
(`true` 는 판매 시연용으로, 날짜가 오늘 기준으로 자동으로 움직입니다.)

### 날짜 적는 법
반드시 `'2027-03-08'` 처럼 **연-월-일** 로 적습니다.

### 줄 늘리는 법 (공정·일지·자재 추가)
`{` 부터 `},` 까지 **한 묶음을 통째로 복사해서 바로 아래에 붙여 넣고** 글자만 바꿉니다.

```js
{ date: '2027-03-09', title: '욕실 방수',
  text: '오늘은 욕실 방수를 했습니다.',
  photos: [ { src: 'images/0309_1.jpg', caption: '욕실 방수' } ] },
```

### 추가·변경 견적 적는 법
늘어난 금액은 그냥, 줄어든 금액은 앞에 **마이너스(-)** 를 붙입니다. 쉼표 없이 숫자만 적습니다.

```js
changes: [
  { date: '2027-03-10', title: '바닥재 변경 (장판 → 강마루)', amount: 1500000 },
  { date: '2027-03-10', title: '욕실 수납장 제외',            amount: -200000 }
],
```

최종 공사금액, 누적 입금액, 남은 금액은 **자동으로 계산**됩니다.
입금 날짜를 오늘보다 뒤로 적으면 그날이 되기 전까지는 '입금 예정'으로 보입니다.

## 4. 사진 넣기

1. 휴대폰 사진을 컴퓨터로 옮겨 `images` 폴더에 넣습니다.
2. 파일 이름은 **영어·숫자로** 짓습니다. 예) `0309_1.jpg`, `bath_after.jpg`
3. `data.js` 에 `'images/0309_1.jpg'` 처럼 적습니다. **대소문자까지 똑같이** 적어야 합니다. (`.JPG` 와 `.jpg` 는 다릅니다)
4. 사진이 너무 크면 화면이 느려집니다. 휴대폰 갤러리의 **크기 조절**로 긴 쪽 1200px 정도로 줄여 넣는 것을 권합니다.
5. 샘플 그림(`images` 안의 `.svg` 파일)은 실제 사진으로 바꾼 뒤 지워도 됩니다.

## 5. 올리기 전에 확인하기

- 폴더 안의 `index.html` 을 **더블클릭**하면 인터넷에 올리기 전에 내 컴퓨터에서 화면을 미리 볼 수 있습니다.
- **화면이 하얗게만 나오면:** `data.js` 에서 지운 쉼표 `,` 나 따옴표 `'` 가 없는지 확인하세요. 문장 안에 작은따옴표를 쓰고 싶으면 `\'` 로 적습니다.
- **날짜별로 미리 보기:** 올린 링크 끝에 `?today=2027-03-15` 를 붙이면 그 날짜 기준으로 진행률·달력을 볼 수 있습니다.

## 6. 카카오톡 미리보기 바꾸기 (선택)

카톡은 프로그램을 읽지 않고 HTML 맨 위 몇 줄만 읽습니다. 그래서 이 부분만 `index.html`·`partner.html` 안에 따로 있습니다.
기본 문구("실시간 현장 리포트 · 공정 진행률과 현장 사진")는 어느 업체에나 맞게 되어 있어 **그대로 써도 됩니다.**

- 회사명을 넣고 싶으면 `index.html` 을 메모장으로 열어 `og:title` 줄의 `content="..."` 안 글자만 바꿉니다.
- 카톡 미리보기에 그림이 안 나오면 `og:image` 줄의 `og-client.png` 를 `https://내주소.netlify.app/og-client.png` 처럼 **전체 주소**로 바꿔 주세요.
- 카톡은 미리보기를 한동안 저장해 둡니다. 바꾼 뒤에도 예전 그림이 나오면 카카오 공유 디버거(developers.kakao.com/tool/debugger/sharing)에서 주소를 넣고 '캐시 초기화'를 누릅니다.

## 7. 꼭 알아 두실 점 (보안·개인정보)

- **링크를 아는 사람은 누구나 볼 수 있습니다.** 검색에는 나오지 않게 설정되어 있지만, 링크가 퍼지지 않게 고객·협력업체에만 보내세요.
- `data.js` 는 고객용·협력업체용이 함께 읽는 파일이라, **협력업체도 마음만 먹으면 정산 금액을 볼 수 있습니다.** 금액을 보이고 싶지 않으면 `PAYMENT` 의 `show` 를 `false` 로 두세요.
- **현관 비밀번호**는 `doorCode` 를 빈칸(`''`)으로 두고 문자로 안내하는 것을 권합니다. 적었다면 완공 후 반드시 지우고, 고객님께 비밀번호 변경을 안내하세요.
- 금액·사진을 올리기 전에 **고객님 동의**를 받으세요.
- 완공 후에도 사이트를 지우지 않으면 고객님이 계속 공사 기록을 볼 수 있습니다. (A/S 때 유용합니다)

## 8. 자주 묻는 질문

**Q. 토요일에도 작업해요.**
`workDays: [1, 2, 3, 4, 5]` 에 `6` 을 더해 `[1, 2, 3, 4, 5, 6]` 으로 적습니다.

**Q. 공사 일차를 달력 날짜로 세고 싶어요.**
`dayBase: 'workday'` 를 `dayBase: 'calendar'` 로 바꿉니다.

**Q. 휴대폰 홈 화면에 앱처럼 깔 수 있나요?**
링크를 연 뒤 크롬은 메뉴(⋮) → **홈 화면에 추가**, 아이폰 사파리는 공유 버튼 → **홈 화면에 추가** 를 누르면 됩니다.

**Q. 정산 탭을 아예 숨기고 싶어요.**
`PAYMENT` 의 `show: false` 로 두면 금액 카드가 숨겨지고 안내 문구만 남습니다.
