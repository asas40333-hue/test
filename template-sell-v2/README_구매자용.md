# 인테리어 현장 공유 웹앱 — 사장님용 사용 설명서

고객님께는 **공사 진행 상황 · 현장 사진 · 공정 달력 · 자재 · 정산 내역**을,
협력업체에는 **현장 주소 · 출입 · 주차 · 공정표 · 작업 수칙**을 휴대폰 링크 하나로 보내 드리는 웹앱입니다.

- 코딩을 몰라도 됩니다. **메모장으로 파일 두 개(`site.js`, `data.js`)의 글자만** 바꾸면 됩니다.
- 무료로 인터넷 주소(링크)를 만들 수 있습니다. (Netlify, 5분)
- 지금 들어 있는 내용은 **시연용 가상 현장(샘플아파트 32평형)** 입니다. 실제 고객 정보는 없습니다.

---

## 0. 먼저 구경해 보기 (1분)

폴더 안의 `index.html` 을 더블클릭하면 인터넷 창(크롬·엣지)으로 고객용 화면이 열립니다.
`partner.html` 은 협력업체용 화면입니다.

> 폴더 안의 파일 이름과 위치는 바꾸지 마세요. 파일끼리 서로 이름으로 찾아갑니다.

## 1. 폴더 안에 무엇이 있나요?

| 파일 | 고치나요? | 하는 일 |
|---|---|---|
| `site.js` | ✏️ **처음 한 번** | 회사 이름, 로고 글자, 색상, 대표님 이름·전화번호, 자재 도감 연결 |
| `data.js` | ✏️ **현장마다** | 현장명, 공사 기간, 공정 일정, 현장일지, 자재 스펙, 특이사항, 도어락·주차 안내, 계약·정산 |
| `images/` | 📷 사진 넣기 | 현장 사진 폴더. `sample-…svg` 는 시연용 그림이라 실제 사진으로 바꿉니다 |
| `index.html` | 고치지 않음 | 고객용 화면 |
| `partner.html` | 고치지 않음 | 협력업체용 화면 |
| `app.js` | 고치지 않음 | 진행률·달력·정산 자동 계산 |
| `icon-192.png` `icon-512.png` `apple-touch-icon.png` | 선택 | 휴대폰 홈 화면 아이콘 |
| `og-client.png` `og-partner.png` | 선택 | 카톡으로 링크 보낼 때 보이는 미리보기 사진 |
| `tools/brand-images.html` | 선택 | 위 아이콘·미리보기 사진을 내 회사 이름으로 만들어 주는 도구 |
| `manifest.json` `manifest-partner.json` | 거의 안 고침 | 홈 화면 바로가기 설정 |

## 2. 파일 고치는 방법 (공통)

1. 파일에 **마우스 오른쪽 클릭 → 연결 프로그램 → 메모장** 으로 엽니다.
   (Mac 은 '텍스트 편집기'. 워드·한글 프로그램으로 열면 안 됩니다)
2. **작은따옴표 `' '` 안의 글자만** 바꿉니다.
3. 저장(Ctrl + S) 후, `index.html` 을 다시 열어(또는 새로고침) 바뀐 것을 확인합니다.

### ⚠️ 이것만 조심하세요
- 따옴표 `'`, 쉼표 `,`, 괄호 `{ } [ ]` 를 지우면 화면이 하얗게 나옵니다.
  → 그럴 땐 방금 고친 곳을 다시 보고 따옴표·쉼표가 빠졌는지 확인하세요.
- 글자 안에 작은따옴표를 쓰고 싶으면 `\'` 처럼 앞에 `\` 를 붙입니다.
- 날짜는 꼭 `'2027-03-02'` 모양(연-월-일, 두 자리씩)으로 적습니다.
- 금액은 쉼표 없이 숫자만: `38000000`

## 3. `site.js` — 회사 정보 (처음 한 번)

```js
name: '샘플 인테리어',        // ← 우리 회사 이름
shortName: '샘플인테리어',     // ← 홈 화면 아이콘 밑 짧은 이름
slogan: '현장 경험 20년 · 꼼꼼한 공정 관리',
logoImage: '',               // ← 로고 사진이 있으면 'images/logo.png'
logoText: '샘플',             // ← 로고 사진이 없으면 동그란 배지에 들어갈 1~2글자
ceoName: '홍길동',
ceoTitle: '대표',
phone: '01012345678',        // ← 숫자만
kakaoUrl: '',                // ← 카카오톡 채널 주소가 있으면 (없으면 버튼이 숨겨짐)
colors: { primary: '#1e3a8a', ... }   // ← 회사 대표 색
```

여기만 바꾸면 고객용·협력업체용 화면의 회사 이름·로고·색·전화 버튼이 **모두 한 번에** 바뀝니다.

### 자재 도감(포트폴리오) 연결 켜고 끄기
회사 자재 도감이나 시공 사례 페이지가 따로 있으면:
```js
catalog: { show: true, url: 'https://내주소/catalog.html', ... }
```
없으면 `show: false` 로 두세요. 자재스펙 탭 맨 위의 파란 안내 상자가 사라집니다.

## 4. `data.js` — 현장 내용 (현장마다)

파일 안에 1번부터 7번까지 칸이 나뉘어 있고, 칸마다 설명이 적혀 있습니다.

| 칸 | 바꾸는 내용 | 화면 |
|---|---|---|
| 1. `SITE` | 현장명, 착공일·완공일, 작업 요일, 휴무일, 소음 시간 | 두 화면 위쪽, 진행률 |
| 2. `SCHEDULE` | 공정 일정 (한 번만 적으면 리스트·달력 모두 반영) | 고객 공정일정 탭 / 협력업체 공정표 |
| 3. `LOGS` | 현장일지 (날짜·제목·설명·사진·확인 사항) | 고객 현장일지 탭 |
| 4. `SPECS` | 자재 스펙 (확정/추천/변경 꼬리표) | 고객 자재스펙 탭 |
| 5. `PARTNER` | 공사 전 사진, 현장 특이사항 | 협력업체 화면 |
| 6. `ACCESS` | 주소, 공동현관, **도어락 비밀번호, 주차**, 작업 수칙 | 협력업체 화면 |
| 7. `PAYMENT` | 계약금액, 회차별 대금, 입금 기록, **추가·변경 견적(+/−)** | 고객 계약·정산 탭 |

### 🔎 가장 먼저! 시연용 날짜 끄기
`data.js` 맨 위 `SITE` 안의 이 줄을 꼭 비워 주세요.
```js
previewToday: ''
```
이 값이 있으면 화면이 그 날짜에 멈춰 있고, 맨 위에 노란 '시연 화면' 띠가 보입니다.
비우면 매일 실제 날짜로 공사 일차·공정률·달력의 '오늘' 표시가 자동으로 바뀝니다.

### 현장일지 하루 추가하기
`LOGS` 안의 묶음 하나를 통째로 복사해 맨 위에 붙이고 글자만 바꿉니다.
```js
{ date: '2027-03-05',
  title: '타일 시공 · 공용 욕실',
  text: '오늘 진행한 내용을 쉬운 말로 적습니다.\n줄을 바꾸려면 \n 을 씁니다.',
  photos: [
    { src: 'images/0305_01.jpg', cap: '01 · 욕실 벽 타일' },
    { src: 'images/0305_02.jpg', cap: '02 · 바닥 타일' }
  ] },
```
- 'N일차'는 날짜를 보고 **자동 계산**됩니다.
- 사진 5장 이상이면 2장만 보이고 나머지는 '펼쳐보기' 버튼 안에 자동으로 들어갑니다.
- 사진 없이 글만 올려도 됩니다: `photos: []`

### 사진 넣기
1. 휴대폰 사진을 컴퓨터로 옮기고, **긴 쪽 1200px 정도로 줄입니다.**
   (윈도우 '사진' 앱 → 크기 조정, 또는 카톡으로 나에게 보내기 후 저장하면 자동으로 줄어듭니다)
2. 파일 이름은 **영어·숫자로** 짓습니다. 예: `0305_01.jpg` (한글·띄어쓰기 이름은 피하세요)
3. `images` 폴더에 넣고 `data.js` 에 `'images/0305_01.jpg'` 로 적습니다.
4. 시연용 그림(`sample-…svg`)은 다 바꾼 뒤 지워도 됩니다.

### 계약·정산과 추가·변경 견적
```js
total: 38000000,          // 기본 계약금액
steps: [ { label: '계약금', ratio: 10, due: '계약 시',
           paid: [{ date: '2026.10.28', amount: 3800000 }] }, ... ],
changes: [
  { date: '2026.11.18', title: '안방 붙박이장 추가', amount: 1200000, note: '고객 요청' },
  { date: '2026.11.25', title: '작은방 몰딩 제외',   amount: -400000, note: '' }
],
changesWith: '잔금'        // 추가·변경 금액을 함께 받을 회차
```
- 회차별 금액, 최종 공사금액, 누적 입금액(%), 남은 금액은 **자동 계산**됩니다.
- 빼는 금액은 앞에 `-` 를 붙입니다.
- 회차 비율(ratio) 합계가 100이 아니면 화면에 빨간 경고가 나옵니다.
- **금액 표시는 고객님 동의를 받은 뒤** 켜 주세요. 숨기려면 `show: false`.

### 도어락 · 주차 안내
```js
doorCode: '',      // 비워 두면 "대표님이 문자로 따로 안내" 로 표시 (권장)
parking: '지하 2층 B구역 · 방문 차량 사전 등록',
```

> ⚠️ **보안 안내** — `data.js` 는 고객용·협력업체용 화면이 함께 읽는 파일입니다.
> 인터넷에 올린 파일은 주소를 아는 사람이 열어 볼 수 있으므로,
> - 도어락 비밀번호는 비워 두고 문자로 따로 보내는 것을 권장합니다.
> - 비밀번호를 적었다면 **완공 후 꼭 지우고** 고객님께 비밀번호 변경을 안내하세요.
> - 계약 금액도 협력업체가 기술적으로 볼 수 있다는 점을 알고 사용하세요.
> - 두 화면 모두 검색엔진(네이버·구글)에는 나오지 않도록 설정되어 있습니다.

## 5. 무료로 링크 만들기 — Netlify Drop (5분)

폴더를 **끌어다 놓기만** 하면 인터넷 주소가 생깁니다.

1. 컴퓨터 크롬에서 **https://app.netlify.com/drop** 에 들어갑니다.
2. 이 템플릿 폴더(`index.html` 이 들어 있는 폴더)를 **통째로** 화면의 점선 상자 안에 끌어다 놓습니다.
3. 몇 초 뒤 `https://영어단어-12345.netlify.app` 같은 주소가 생깁니다. 눌러서 화면을 확인합니다.
4. **무료 회원가입을 꼭 합니다.** (구글 계정으로 가입 가능)
   가입하지 않고 올린 사이트는 잠시 뒤 사라질 수 있습니다. 화면 안내에 따라 사이트를 내 계정에 저장(Claim)하세요.
5. 주소 이름 바꾸기(선택): 사이트 화면 → **Site configuration → Change site name** →
   예: `sample-interior-1203` → 주소가 `https://sample-interior-1203.netlify.app` 로 바뀝니다.

### 보낼 링크
- 고객님께: `https://내주소.netlify.app/`
- 협력업체에: `https://내주소.netlify.app/partner.html`

### 내용 고친 뒤 다시 올리기 (매일 일지 올릴 때)
1. 컴퓨터에서 `data.js` 와 사진을 고칩니다.
2. Netlify 사이트 화면 → **Deploys** 탭으로 갑니다.
3. 아래쪽 "Drag and drop your site output folder here" 상자에 **폴더를 다시 통째로** 끌어다 놓습니다.
4. 주소는 그대로이고 내용만 바뀝니다. 고객님 휴대폰에서 새로고침하면 반영됩니다.

> Netlify 화면 메뉴 이름은 회사 사정에 따라 조금씩 바뀔 수 있습니다. 위 이름이 안 보이면 비슷한 메뉴를 찾아보세요.

### 현장이 여러 개일 때
현장마다 **폴더를 통째로 복사**해 따로 올리면 됩니다. (현장마다 Netlify 사이트 하나)
`site.js` 는 그대로 두고 `data.js` 와 사진만 바꾸면 됩니다.
`data.js` 의 `id` 는 현장마다 다르게 적어 주세요.

## 6. 카톡 미리보기 · 홈 화면 아이콘 (선택)

### 내 회사 이름으로 이미지 만들기
1. `site.js` 를 내 회사 정보로 고친 뒤, `tools/brand-images.html` 을 더블클릭해 엽니다.
2. 미리보기 사진 2장과 아이콘 3개가 내 회사 이름·색으로 그려집니다.
3. 각각 **[저장]** 버튼을 눌러 내려받고, 같은 이름 그대로 `index.html` 옆에 덮어씁니다.

### 카톡 미리보기 제목 바꾸기
카카오톡은 화면 프로그램을 읽지 않기 때문에, 미리보기 제목은 `index.html`·`partner.html` 맨 위에 직접 적혀 있습니다.
회사 이름을 넣고 싶다면 메모장으로 열어 `og:title` 줄의 글자만 바꾸세요. (나머지 코드는 건드리지 않습니다)

### 카톡에서 미리보기 사진이 안 보일 때
링크 주소가 생긴 뒤, 두 파일의 `og:image` 줄을 **전체 주소**로 바꾸면 확실하게 보입니다.
```html
<meta property="og:image" content="https://내주소.netlify.app/og-client.png">
```
(`partner.html` 은 `og-partner.png`)
그래도 예전 미리보기가 보이면 카카오의 '공유 디버거'에서 내 주소를 넣고 캐시 초기화를 누르세요.

## 7. 확인하는 법 (날짜 바꿔 보기)

주소 끝에 `?today=날짜` 를 붙이면 그날 기준으로 화면을 미리 볼 수 있습니다.
```
https://내주소.netlify.app/?today=2027-03-01   ← 착공 전날
https://내주소.netlify.app/?today=2027-03-10   ← 공사 중
https://내주소.netlify.app/?today=2027-04-01   ← 완공 후
```
진행률 카드, 공정표의 '진행 중' 표시, 달력의 오늘 표시가 맞게 바뀌는지 봅니다.

## 8. 자주 묻는 질문

**Q. 화면이 하얗게 나와요.**
방금 고친 `site.js`/`data.js` 에서 따옴표 `'` 나 쉼표 `,` 가 빠졌을 가능성이 큽니다. 고치기 전 파일을 복사해 두는 습관을 들이면 바로 되돌릴 수 있습니다.

**Q. 사진이 안 나와요.**
`images` 폴더에 넣었는지, `data.js` 의 파일 이름과 실제 파일 이름(대소문자, `.jpg`/`.JPG`)이 똑같은지 확인하세요.

**Q. 휴대폰 홈 화면에 앱처럼 깔 수 있나요?**
네. 고객님께 링크를 연 뒤 아이폰은 공유 버튼 → '홈 화면에 추가', 갤럭시는 메뉴 → '홈 화면에 추가'를 안내하세요.

**Q. 토요일도 작업해요.**
`data.js` → `workDays: [1, 2, 3, 4, 5, 6]` 처럼 6을 추가하세요.

**Q. 공사 일차를 주말 포함으로 세고 싶어요.**
`dayBase: 'calendar'` 로 바꾸세요. 기본값 `'workday'` 는 작업일만 셉니다.

**Q. 완공 후에는요?**
도어락 비밀번호를 적었다면 지우고 다시 올리세요. 사이트는 지우지 말고 두면 고객님이 사진 기록을 계속 볼 수 있습니다.
